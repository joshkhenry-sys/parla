# Nahtive Product Bible

## Mission
Speak like a native. Live like a local.

## Desktop-first roadmap

### Sprint 1: Voice-first lessons
- Native audio button on every new phrase.
- Slow playback.
- AI pronunciation feedback.
- Repeat-after-me flow before quizzes.

### Sprint 2: Real-world lesson engine
- Cinematic scene intro.
- Listen -> Understand -> Speak -> Conversation -> Reflection.
- No vocabulary dump.

### Sprint 3: Learner Memory
- Resume exactly where the learner left off.
- Track hesitation, pronunciation, confidence, and review items.
- Adaptive review.

### Sprint 4: AI Conversation
- Hotel, café, airport, work, dating, and daily-life roleplay.
- Native Mode with slang and idioms.

## Design principles
- Black, ivory, charcoal, electric cobalt.
- Large typography.
- Rounded cards.
- Premium motion.
- Every button has a text label.
- No repeated onboarding.
